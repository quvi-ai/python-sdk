# Contributing to QUVIAI Python SDK

Thank you for your interest in contributing!

## How to Contribute

1. **Fork** this repository
2. **Create a branch** from `main`: `git checkout -b feature/your-feature`
3. **Make your changes** following the guidelines below
4. **Run the tests**: `python -m pytest`
5. **Open a Pull Request** against `main`

All PRs are reviewed by the maintainer. Please do not merge your own PRs.

## Code Guidelines

- Python 3.10+ syntax, type hints on all public functions
- Zero external dependencies — stdlib only
- No secrets, credentials, or personal data in code or tests
- Keep commits atomic and commit messages imperative
  (`Add retry logic`, not `Added retry logic`)

## Reporting Bugs

Use [GitHub Issues](../../issues).
For security vulnerabilities, see [SECURITY.md](SECURITY.md).
