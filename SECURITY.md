# Security Policy

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Email us at **support@quvi.ai** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact assessment

We will acknowledge receipt within 48 hours and aim to resolve confirmed
vulnerabilities within 14 days.

## Scope

- SDK authentication and credential handling
- API communication security (HTTPS, header injection)
- Dependency security

## Out of Scope

- The QUVIAI backend API itself — contact us directly for backend issues
- Vulnerabilities in Python itself or its standard library
